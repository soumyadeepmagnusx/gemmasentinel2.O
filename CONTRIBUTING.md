# Contributing to GemmaSentinel Voice & Cloud 🎃

Thank you for your interest in contributing to **GemmaSentinel** during Hacktoberfest 2026!

## 🚀 How to Contribute

1. **Fork the Repository** and clone it locally.
2. **Create a Feature Branch:**
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Run the Test Suite:**
   Make sure all tests pass:
   ```bash
   pytest tests/
   ```
4. **Follow the Open-Source Standards:**
   - Adhere to PEP 8 standards.
   - Ensure all database queries follow Oracle Autonomous Database parameterization guidelines.
   - Never commit `.env` or plaintext API tokens.
5. **Submit a Pull Request:**
   Our automated GitHub Actions CI pipeline will run security checks on your PR.
